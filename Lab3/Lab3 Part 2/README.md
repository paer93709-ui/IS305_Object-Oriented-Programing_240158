# 1. Project Description

This project extends the Dining Meal Booking application developed in Labs 1 and 2.

The Lab 3 Distinction extension introduces a dining account system that allows students to pay for meal bookings.

The application demonstrates:

- Encapsulation
- Private class fields
- Class inheritance
- Constructor chaining
- Method overriding
- Polymorphism
- Simulated method overloading
- Object composition
- Arrays of related objects
- Transaction processing
- Validation
- Exception handling
- Meal booking payment integration
